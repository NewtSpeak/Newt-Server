# 级联信令与 Cascade Token（M3 定稿）

对齐设计文档 [08 级联协议与 Anchor](../设计讨论/2026-07-20-08-级联协议与Anchor.md) 与
[15 SFU 节点实现选型 §3 BG](../设计讨论/2026-07-20-15-SFU节点实现选型.md)。
本文记录 M3 实现的线协议与实现决策；控制通道指令定义见
[`proto/owlsfu/v1/control.proto`](../../proto/owlsfu/v1/control.proto)。

## 1. 承载与端口

| 项 | 定稿 |
|----|------|
| 信令承载 | **mTLS TCP 上的流式 JSON 帧**（`json.Encoder/Decoder`，无需额外分帧） |
| 端口 | tcp/**8843**（可配 `cascade_listen` / `NEWTSFU_CASCADE_LISTEN`） |
| 方向 | **child 主动连 parent**（BG.2）；每条边一条 TCP 连接 |
| 证书 | 双向节点证书（enrollment 签发，CN/DNS SAN = node_id）+ 集群 CA 池互验 |
| 媒体 | 每条边两个单向 WebRTC PC（`dir=up`：child→parent 为 offerer；`dir=down`：parent→child 为 offerer），单方向单 offerer 天然规避 glare |

**选型理由**：不用 WebSocket/gRPC 而用裸 mTLS + JSON 流——节点间是固定拓扑的内部长连接，
无需 HTTP 升级握手与路由；`json.Encoder` 流式编解码天然自分帧，实现最小且与客户端信令
（WSS+JSON）风格一致，便于排障时肉眼读帧。

> **与 15 BH.1 的偏离**：BH.1 要求「客户端 PC 与级联 PC 共用单端口 UDPMux」。实测同一对
> 节点间存在多条 PC（上/下行方向 × 房间数），双端都走单口 mux 时这些 PC 的 UDP 四元组完全
> 相同，而 pion UDPMux 对非 STUN 包按对端地址路由，同地址对只能承载一个 DTLS 会话，多 PC
> 互相抢占导致媒体断续。故 **级联 PC 改用独立 ephemeral UDP 端口直连**（BG.4 host candidate
> 语义不变；`public_ip` 以 srflx 附加候选形式通告）。单口复用留待二期「节点对单 PC + slot
> 复用」（BG.3 二期项）一并解决。见 `Newt-SFU/internal/sfu/engine.go`。

## 2. 帧格式

`{"t": "<类型>", ...}`，类型与字段：

| t | 方向 | 字段 | 说明 |
|---|------|------|------|
| `hello` | child → parent | `room_id, epoch, child, token` | 首帧；`child` 必须与 TLS 证书 CN 一致 |
| `hello_ack` | parent → child | `ok, reason` | 拒绝原因见 §3 |
| `offer` / `answer` | 双向 | `dir, sdp` | `dir=up|down` 标识所属媒体 PC |
| `ice` | 双向 | `dir, candidate, sdp_mid, sdp_mline` | trickle ICE |
| `want` | 双向 | `want: {all, uids[]}` | NodeWant 通报（08 §5.1）：`all=true` 时 `uids` 为排除集，否则为需要集；语义 = 「我方需要你送来的 speaker 集合」 |
| `ping` / `pong` | 双向 | `ts` | 5s 周期 RTT 探测（EdgeStatus.rtt_ms 来源）；25s 无帧判边断 |

媒体轨约定：track id = 源会话 `sid`、streamID = 源 `uid`，对端经 msid 还原 speaker 身份；
每个 speaker 一条 audio track，上下麦触发 renegotiation（BG.3）。

## 3. 三重校验（BG.2 / 08 E.4）

parent 收到 `hello` 后按序校验，任一不过即拒（`hello_ack.reason` 计入
`owlsfu_cascade_handshake_failed_total{reason}`）：

1. **证书身份**（`cert_mismatch`）：`hello.child` == TLS 对端证书 CN；
2. **边授权**（`unknown_room` / `epoch_mismatch` / `edge_not_authorized`）：
   (parent=本机, child) 必须在本机当前 epoch 的 `SetCascadeEdges` 边集内——未经 Server
   下发的边一律拒绝（08 C.3 禁止私自互联）；
3. **cascade token**：
   - `token_mismatch`：与本机持有的该边 token 副本恒时比较不一致；
   - `token_invalid`：签名校验失败（EdDSA、Media Token 同源公钥，按 kid）、已过期、
     或 claims 与 (room, epoch, parent, child) 绑定不符。

「不出池」（08 §6.3）由 Server 在建边前校验（`Newt-Server/internal/voice`），拒发池外边。

## 4. Cascade Token

由 Newt-Server 用 **Media Token 同源 Ed25519 密钥** 签发（`internal/mediatoken.SignCascade`），
SFU 侧用 Enroll/RegisterAck 已下发的验签公钥校验（`internal/auth.VerifyCascade`）：

```json
{
  "v": 1, "typ": "cascade",
  "rid": "<logical_room_id>", "epoch": 3,
  "parent": "<parent_node_id>", "child": "<child_node_id>",
  "iat": 0, "exp": 0, "jti": "<uuid>"
}
```

- TTL **5 分钟**；Server 租约续约循环（每 60s）随 `SetCascadeEdges` 幂等重发轮换，
  同 epoch 重发不拆边（token 轮换仅影响后续新握手）。
- token 经 `SetCascadeEdges` 同时下发边两端；child 在 `hello` 中出示。

## 5. Server 编排语义（08 §4.3 落地）

- **AnchorLease**：每 logical_room 一行（`voice_anchor_leases`：anchor + epoch + 过期 +
  degraded 标记）。首个进房用户所在节点 = 初始 Anchor（B.3），epoch 从 1 起。
  租约必须下发给 **anchor 与全部涉边节点**（SFU 侧每节点都要求 epoch 匹配 + 未过期才转发）。
- **进房挂边顺序**：`EnsureLogicalRoom(N)` → 续约/建租约 → 建边落库（星型深度 1；hub
  深度 2 留接口未实装）→ 签发 cascade token → `SetAnchorLease` + `SetCascadeEdges`（全量边集）
  → **等待 `EdgeStatus(EDGE_UP)`（超时 5s）** → 才返回 join 响应；超时摘边回滚，
  上层换 fallback 节点或 503（08 §10）。
- **EdgeDown**：SFU 上报 → `internal.EDGE_DOWN` 事件 → voice 编排：
  - 旧 epoch / 已不在图中的边：忽略；
  - 根节点离线：仅标记 `degraded` + 日志（完整切根属 M4；心跳判死后由
    InternalNodeDown → 迁移引擎 → reRoot 兜底）；
  - 叶边断且根存活：幂等重发当前边集（刷新 token/端点），SFU child 拨号循环自动重连。
- **换根**（房内 anchor 节点空出/死亡）：冻图（持锁）→ electAnchor（人最多 → 负载低 →
  region → node_id）→ 升 epoch → 重建星型边 → 整体下发。
- **回收**：房间无人时删除租约与边、对全部涉及节点 `CloseLogicalRoom`（SFU 侧同步拆
  级联状态与边会话）。

## 6. 观测（08 §11）

SFU `/metrics`（与信令同端口）：

| 指标 | 含义 |
|------|------|
| `owlsfu_cascade_edges` / `edge_up_total` / `edge_down_total` | 边数与状态迁移 |
| `owlsfu_cascade_edge_rtt_ms{room,peer_node}` | 每边信令 RTT（ping/pong） |
| `owlsfu_cascade_edge_bytes_total` / `packets_total{room,peer_node,dir}` | 每边收发流量 |
| `owlsfu_cascade_outbound_tracks{state=active\|pruned}` | 出向轨活跃/被剪数（剪枝率 = pruned/(active+pruned)） |
| `owlsfu_cascade_loop_dropped_total` | 环路/非预期来源丢弃（08 C.5） |
| `owlsfu_cascade_lease_expired_total` | 租约过期停转发次数 |
| `owlsfu_cascade_handshake_failed_total{reason}` | 握手失败按原因 |

（双节点跨节点互听 + NodeWant 剪枝，独立数据库可重复运行）。
