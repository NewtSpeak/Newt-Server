## 1. 目标

| 目标 | 说明 |
|------|------|
| 文字频道可用 | 发送、历史、实时、编辑、删除 |
| 可审计编辑 | 全文编辑快照 + UI 编辑次数 |
| 附件 | 预签名直传对象存储；类型不限；预览白名单；每服大小上限 |
| 搜索 | **全系统搜索**，强制权限过滤 |
| 存储 | **PostgreSQL** 消息主存 + **对象存储** 附件 |

## 2. 消息本体（AP）

| 编号 | 定稿 |
|------|------|
| **AP.1** | 消息 ID：**雪花 ID**（或 ULID），可时间排序 |
| **AP.2** | 内容：**纯文本 + 有限 Markdown**（粗体/斜体/链接/行内代码/代码块等）；渲染防 XSS |
| **AP.3** | 最大长度：**4000** 字符（可配） |
| **AP.4** | 允许 **仅附件**；禁止正文与附件皆空 |
| **AP.5** | `type` 区分普通/系统消息；系统消息首期少量 |
| **AP.6** | **单层** `reply_to_id` 引用回复；完整线程二期 |

### 2.1 逻辑字段

```text
Message {
  id
  guild_id
  channel_id
  author_id
  type: DEFAULT | SYSTEM_…
  content: string
  reply_to_id?
  attachment_ids[]
  edit_count: int          // 冗余
  edited_at?
  created_at
  deleted_at?              // 软删
  nonce?                   // 客户端幂等
}
```

## 3. 存储（AQ）

| 编号 | 定稿 |
|------|------|
| **AQ.1** | 主表 `messages`（含 guild_id, channel_id 便于隔离与分区） |
| **AQ.2** | 分区策略实现期定（时间 / channel 哈希）；逻辑模型不依赖 |
| **AQ.3** | **软删除** `deleted_at`；用户侧 tombstone/404；审计可查 |
| **AQ.4** | `message_edits`：**每次编辑存全文快照**（非仅 diff） |
| **AQ.5** | `messages.edit_count` 与历史表行数一致 |

```text
MessageEdit {
  message_id
  version: int             // 1..edit_count
  content
  edited_at
  editor_id                // 通常=author
}
```

附件元数据表 `attachments`：object_key、mime、size、uploader、message_id?、created_at 等。

---

## 4. 发送与拉取（AR）

| 编号 | 定稿 |
|------|------|
| **AR.1** | `POST /channels/{id}/messages` |
| **AR.2** | `GET /channels/{id}/messages?before=&after=&limit=` 游标分页 |
| **AR.3** | 需 `VIEW_CHANNEL`；拉历史另需 **`READ_MESSAGE_HISTORY`**。无 HISTORY：**只收进频后实时**，历史接口按不可见策略 **404** |
| **AR.4** | `limit` 默认 **50**，最大 **100** |
| **AR.5** | Gateway：`MESSAGE_CREATE` / `MESSAGE_UPDATE` / `MESSAGE_DELETE` |
| **AR.6** | 客户端 **`nonce` 幂等** 防重提交 |

发送权限：`SEND_MESSAGES` + Restriction 未禁发 + 频道可见。

---

## 5. 编辑与删除（AS）

| 编号 | 定稿 |
|------|------|
| **AS.1–2** | **仅作者可编辑正文**；`MANAGE_MESSAGES` **可删不可改他人正文** |
| **AS.3** | **无编辑时间窗**（默认可一直改；可后续加配置） |
| **AS.4** | UI：`edited` + **`edit_count`** |
| **AS.5** | **完整编辑历史**：作者、`MANAGE_MESSAGES`、系统管；普通人只见次数 |
| **AS.6** | 删除：作者或 `MANAGE_MESSAGES`；软删；`MESSAGE_DELETE` |
| **AS.7** | 首期编辑 **只改文本**；附件增删另议/二期 |

编辑流程：写 `message_edits` → 更新 `content/edit_count/edited_at` → 广播 `MESSAGE_UPDATE` → 异步更新搜索索引。

---

## 6. 附件（AT）

| 编号 | 定稿 |
|------|------|
| **AT.1–2** | **预签名直传对象存储**，再 `POST message` 带 `attachment_ids` |
| **AT.3** | 每消息最多 **10** 个附件 |
| **AT.4** | 单文件上限：**系统管按 Guild 配置**；平台默认 **25MB** |
| **AT.5** | 存储 MIME 不限；**预览白名单**：图片、音频、视频、PDF |
| **AT.6** | 病毒扫描 **二期**；首期可异步标记 |
| **AT.7** | 下载 **短时签名 URL**；校验频道 `VIEW` |
| **AT.8** | 消息软删后附件 **延迟 GC，默认 7 天** |

### 6.1 上传时序

```text
1. POST /channels/{id}/attachments/presign { filename, size, mime }
2. Server: 校验大小≤服上限、数量配额 → 返回 upload_url + attachment_id
3. Client PUT 对象存储
4. POST /messages { content, attachment_ids, nonce }
5. Server: 确认对象存在且属该用户 → 绑定 message_id
```

未绑定消息的 attachment 定时清理（防垃圾上传）。

## 7. 全系统搜索（AU）

| 编号 | 定稿 |
|------|------|
| **AU.1–2** | 引擎：**OpenSearch / Elasticsearch 类** 专用索引（非仅 PG FTS） |
| **AU.3** | 范围：调用者 **可见** 的 guild/channel 并集（成员 + `VIEW_CHANNEL` + Restriction 未禁看） |
| **AU.4** | 过滤：guild、channel、author、时间范围 |
| **AU.5** | 索引：当前正文、author、channel/guild 元数据 |
| **AU.6** | 索引更新 **异步秒级** 可接受 |
| **AU.7** | **不搜索** 历史编辑版本（仅当前 content） |
| **AU.8** | **严格按用户限流** |

### 7.1 API（逻辑）

```text
GET /search/messages?q=&guild_id=&channel_id=&author_id=&before=&after=&limit=
```

查询层 **强制** 注入 ACL filter；禁止客户端传「跳过权限」。  
软删消息出索引；禁看频道变更触发权限侧过滤（索引可留，查询滤掉，或异步删索引）。

## 10. 与 Restriction / RBAC

| 能力 | 权限 |
|------|------|
| 看频道/收实时 | `VIEW_CHANNEL` 且无禁看 Restriction |
| 拉历史 | + `READ_MESSAGE_HISTORY` |
| 发送 | `SEND_MESSAGES` 且无禁发 |
| 反应 | `ADD_REACTIONS` |
| 删他人 | `MANAGE_MESSAGES` |
| 搜索命中 | 可见频道内 + 上述可见性 |

无权限频道：**404**，不在搜索结果中暴露存在性。

## 12. 结论汇总

| # | 结论 |
|---|------|
| 1 | PG 消息 + 对象存储附件；雪花 ID；有限 MD；4000 字；单层回复 |
| 2 | 软删；编辑全文快照；仅作者编辑；无时间窗；历史作者+管理可见 |
| 3 | 无 HISTORY 只实时；limit 50/100；nonce 幂等 |
| 4 | 预签名直传；每消息 10 附件；默认 25MB/服可调；预览四类；GC 7 天 |
| 5 | OpenSearch 类全系统搜索；秒级索引；不搜旧版；ACL 强制 |
| 6 | 反应首期；置顶二期；消息默认永久可配保留 |
