## 1. 目标

| 目标 | 说明 |
|------|------|
| 媒体路径 | 屏幕轨经 **Newt-SFU 选路转发**，**不经** Newt-Server 转 RTP |
| 权限 | `STREAM` / `STREAM_QUALITY`；STAGE 仅台上；FREE 有权即可 |
| 配额 | **无固定全局硬顶**；每服基准上限 + **负载动态有效上限**（≤ 基准） |
| 可控 | 系统管配置；可结束他人共享；Server **审批后** 才 `publish_screen` |

---

## 2. 谁可以开共享（AX）

| 编号 | 定稿 |
|------|------|
| **AX.1** | **STAGE**：须为 **SPEAKER** + 拥有 `STREAM` + 未被禁说/server_mute |
| **AX.2** | **FREE**：在语音频道内 + 拥有 **`STREAM`** 即可 |
| **AX.3** | 必须 **当前在该语音频道**（VoiceState 已加入） |
| **AX.4** | 同一用户同时默认 **1 路** 屏幕（多路二期） |

听众（STAGE 下 AUDIENCE/QUEUED）**不可** 共享。

---

## 3. 配额模型（AY）

### 3.1 两级上限

| 层级 | 定稿 |
|------|------|
| **Guild 基准** | `guild.max_concurrent_screens`，系统管可调；**新服默认 3**（AY.7） |
| **频道上限（AY.2）** | `channel.max_concurrent_screens`，默认 **2**；实际允许 = min(频道剩余, 服有效剩余) |
| **有效服上限** | `effective = min(基准, dynamic_cap)`；动态关闭时 `effective = 基准` |

### 3.2 动态降额（AY.4–AY.6）

| 项 | 定稿 |
|----|------|
| 开关 | 平台级 `dynamic_screen_quota_enabled` |
| 输入 | 服节点池内 SFU：**出口带宽、CPU、屏幕轨数** 等聚合 |
| 输出 | `dynamic_cap` 随负载升高而 **下降** |
| 约束 | **有效上限永不高于配置基准**；负载恢复后可缓慢抬升，不超过基准 |

### 3.3 成本权重（BD）

| 项 | 定稿 |
|----|------|
| **BD.1** | 一路屏幕相对语音的 **权重系数可配**（用于动态 f(load) 与调度） |
| **BD.2** | 数值 **压测后标定**；实现可先给初值表（如 720p/1080p 不同系数） |
| **BD.3** | SFU 上报：屏幕轨数、分辨率、出口 bps |

系统音频伴轨：**不另占「屏幕路数」配额**（BA.4），但仍计入带宽权重。

---

## 4. 占坑、拒绝与超限（AZ）

| 编号 | 定稿 |
|------|------|
| **AZ.1** | 满额新开 → **拒绝** + 错误码（如 `SCREEN_QUOTA_EXCEEDED`） |
| **AZ.2** | 持 **`STREAM_END_OTHERS`**（或等价节点）可 **强制结束他人共享** |
| **AZ.3** | 动态下调导致当前占用 > 有效上限：  
| | ① **拒绝新开**；  
| | ② 可配：仍超则 **结束最早开启** 的共享（默认建议开启温和策略，实现可配） |
| **AZ.4** | 占坑：`PREPARE` 预留 → 发布成功确认 → 失败/超时释放（防超卖） |

```text
ScreenSlot {
  guild_id, channel_id, user_id
  reservation_id?
  state: RESERVED | ACTIVE
  quality_tier
  started_at
  node_id
}
```

## 5. 质量与协商（BA）

| 编号 | 定稿 |
|------|------|
| **BA.1** | 档位：**480p / 720p / 1080p**，帧率约 5–30（客户端能力范围内） |
| **BA.2** | 上限：服配置 + **平台天花板**；高负载时压低 **最高可用档** |
| **BA.3** | SFU **不转码**；降质靠客户端 simulcast / 选层（若实现） |
| **BA.4** | 系统音频与屏幕同一共享会话，**不占第二路屏幕配额** |

`STREAM_QUALITY`：控制用户可选最高档（角色/服策略）。

---

## 6. 与舞台 / 级联 / 迁移（BB）

| 编号 | 定稿 |
|------|------|
| **BB.1** | **抱下 / 失去 SPEAKER** → **自动结束共享** 并释配额 |
| **BB.2** | 热迁移：**音画同迁**，保留共享意图，迁后恢复 `publish_screen` |
| **BB.3** | 级联：屏幕 track **选路 RTP + 订阅剪枝**；调度可对共享者加权近锚点/多数观众 |
| **BB.4** | 断线后 **60s** 内重连 **保留配额与会话意图**；超时释放 |

FREE 模式离开语音频道 → 结束共享。

## 7. API 与 caps（BC / BE）

### 7.1 流程（BC.1）

```text
1. Client → Server: POST /channels/{id}/voice/screen/start { quality? }
2. Server: RBAC STREAM + 舞台角色 + Restriction + 配额预留
3. Server: 刷新/签发 Media Token，caps ⊇ publish_screen (+ quality hints)
4. Client: 向当前 SFU publish 屏幕轨
5. SFU: 校验 token caps；上报 track active
6. Server: RESERVED → ACTIVE；广播 SCREEN_SHARE_START / VOICE_STATE
```

结束：`POST .../screen/stop` 或 track ended / 抱下 / 超时 → 释配额 → 广播结束。

### 7.2 查询与治理

| 接口 | 作用 |
|------|------|
| `GET /guilds/{id}/screen-quota` | 基准上限、有效上限、当前占用、动态开关状态 |
| 系统管平台 API | 调各服基准、动态开关、权重、平台清晰度天花板、展示策略文案 |

### 7.3 展示策略（BC.5）

系统管可配：**默认清晰度、是否提示全屏/带宽警告** 等产品文案与默认值。  
**不是** 对屏幕内容做 RTP 级审查。

### 7.4 权限节点（BE）

| 节点 | 说明 |
|------|------|
| `STREAM` | 发起共享 |
| `STREAM_QUALITY` | 可选更高档 |
| `STREAM_END_OTHERS` | 结束他人共享（BE.2 **独立权限**） |

同频道成员通过 Gateway 事件知悉谁在共享。

---

## 8. 事件（逻辑）

| 事件 | 说明 |
|------|------|
| `SCREEN_SHARE_START` | user、channel、quality |
| `SCREEN_SHARE_STOP` | reason：self / admin / demote / quota / disconnect |
| `SCREEN_QUOTA_UPDATE` | 有效上限变化（可选，便于 UI） |
| `VOICE_STATE_UPDATE` | 可带 `self_stream: true` |

---

## 9. 错误码（逻辑）

| 码 | 含义 |
|----|------|
| `STREAM_PERMISSION` | 无 STREAM |
| `STAGE_SPEAKER_REQUIRED` | 舞台下非台上 |
| `NOT_IN_VOICE` | 未在语音频道 |
| `SCREEN_QUOTA_EXCEEDED` | 服/频道/动态有效上限不足 |
| `SCREEN_ALREADY_ACTIVE` | 已有一路 |
| `SCREEN_QUALITY_NOT_ALLOWED` | 超过允许档 |

## 10. 观测指标

- 同时屏幕路数 by guild、拒绝次数、动态降额触发次数  
- 掐最早共享次数、管理结束他人次数

## 11. 结论汇总

| # | 结论 |
|---|------|
| 1 | STAGE 仅台上；FREE+STREAM 可共享；每用户 1 路；须在语音频道 |
| 2 | 服基准默认 3；每频道默认 2；动态有效上限 ≤ 基准 |
| 3 | 满额拒绝；预留占坑；动态超限拒新并可配掐最早 |
| 4 | 三档清晰度；不转码；系统音频不另占路数 |
| 5 | 下麦停共享；迁移保留；断线 60s 留配额 |
| 6 | Server 审批后 publish_screen；结束他人独立权限 |
| 7 | 权重可配，压测标定 |
