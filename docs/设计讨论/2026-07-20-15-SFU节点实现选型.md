## 1. 目标

补齐 05 §15「仍待专项」中与 SFU 代码骨架直接相关的实现选型（token 携带方式、级联承载、检出阈值），并给出 Newt-SFU 进程结构与里程碑，作为建仓与 M0 协议起草的依据。

## 2. 客户端 ↔ SFU 信令通道（BF）

| 编号 | 定稿 |
|------|------|
| **BF.1** | SFU 自带 **WSS 信令端点**（HTTPS 端口，默认 tcp/443 可配）；入会 SDP 协商、trickle ICE、renegotiation 均走此通道 |
| **BF.2** | **Media Token 在 WS 首帧鉴权**（不放 URL query，防日志泄露）；验签失败立即关闭并返回 05 §3.3 原因码 |
| **BF.3** | 同通道承载：**订阅控制**（静音=退订，对齐 08 D.5）、`speaking` 事件推送（节点解析 RFC 6464 audio level 聚合，节流 ~250ms）、迁移期新节点入会 |
| **BF.4** | **证书要求**：WSS 端点必须使用 **浏览器可信证书**（ACME 自动签发/续期）；私有 CA 节点证书 **不用于** 客户端侧。部署要求：每节点一个域名或泛域名（如 `*.sfu.<domain>`），enrollment 时上报 advertise 域名 |
| **BF.5** | **RTT 探测**（对齐 10 §7 S.2）：首期复用 HTTPS 端口 `GET /rtt`（轻量、无鉴权、限速）；二期可加 UDP echo（限包长与速率，防放大攻击） |

> 不采用「SDP 经 Newt-Server 中转」：订阅变更是高频操作，绕控制通道增加时延与 Server 负担；Server 仍通过控制通道保有踢人/改 caps 的权威路径，权威模型不变。

### 2.1 订阅信令路径

```text
客户端静音某 speaker → WSS: Unsubscribe(speaker)
SFU: 本地校验（仅可订阅本 room 内已授权 track）→ 更新本地订阅图
SFU: 聚合 NodeWant → 沿级联树向上剪枝（08 §5.1）
SFU → Server: 订阅摘要随心跳/事件上报（观测与审计用，非授权路径）
```

## 3. 级联媒体承载（BG）

| 编号 | 定稿 |
|------|------|
| **BG.1** | 节点间媒体 = **WebRTC PeerConnection（Pion ↔ Pion，DTLS-SRTP）**，复用与客户端一致的媒体栈 |
| **BG.2** | 节点间信令：**child 主动连 parent 的级联端口（mTLS，双向节点证书校验）**，并出示 Server 签发的 **cascade token**（绑定 `logical_room_id + epoch + edge`，短 TTL，对齐 08 E.4）；三重校验（池内 + 证书 + token）通过才协商 PC |
| **BG.3** | 边上 **每 speaker 一条 audio track**，上下麦触发 renegotiation（台上硬顶 50 使频率可控）；**二期** 优化为固定 slot 复用免 renegotiation |
| **BG.4** | 级联 ICE 仅用 **host candidate**（节点公网/内网 IP 直连），不经 TURN；EdgeUp/EdgeDown/RTT 经控制通道上报（08 §6.1） |
| **BG.5** | QUIC 自定义隧道 **不作为首期方案**；若压测显示 renegotiation 或 DTLS-SRTP 成瓶颈，二期立项评估 |

## 4. 端口与网络（BH）— 修订 04 §5.2

| 编号 | 定稿 |
|------|------|
| **BH.1** | 媒体 UDP：**单端口 UDPMux（默认 udp/3478，可配）**，客户端 PC 与级联 PC 共用；**废止** 04 的 10000–20000 端口范围默认值 |
| **BH.2** | 高并发下可 SO_REUSEPORT 多 listener 分摊单口负载（实现期压测定） |
| **BH.3** | ICE-TCP / TURN 兜底：TURN 独立部署（维持 04 结论）；ICE-TCP 二期可选 |

### 4.1 节点端口清单

| 端口 | 方向 | 用途 | 证书 |
|------|------|------|------|
| tcp/443（可配） | 监听（公网） | 客户端 WSS 信令 + `/rtt` | 公网可信（ACME） |
| tcp/8843（可配） | 监听（节点间） | 级联 mTLS 信令 | 私有 CA 节点证书 |
| udp/3478（可配） | 监听（公网） | 全部 WebRTC 媒体（UDPMux） | DTLS-SRTP |
| — | 外连 | 控制通道 gRPC → Server；enrollment | 私有 CA 节点证书 |

控制通道与 enrollment 均为 SFU 主动外连（03 §5.1），节点无需为其开监听口。

## 5. 死亡检出增强（BI）— 修订 09 §3.2

| 编号 | 定稿 |
|------|------|
| **BI.1** | 心跳间隔收紧为 **5s**；「连续 3 次失败」语义保留 → **硬判死上限 15s**（09 原 15–30s 收窄） |
| **BI.2** | 新增 **提前信号源**：① 级联邻居上报 `EdgeDown`（且该节点无其它健康证据）；② 客户端 ICE disconnected/failed 经 Gateway 批量上报 |
| **BI.3** | 组合规则（阈值实现期可调）：**≥2 个独立信号源 + ≥1 次心跳失败** 即可提前判死，无需等满 3 次 |
| **BI.4** | 判死权威 **仍仅 Newt-Server**（维持 09 §3.3，防脑裂）；提前信号只是证据来源，不授予 SFU/客户端判死权 |

> 动机：07 SLA 目标「秒级内自动恢复」，而静音窗口 ≈ 检出时间 + 迁移时间，迁移仅数秒，检出是大头。

## 6. Media Token 增补 `sid`（BJ）— 修订 03 §6

| 编号 | 定稿 |
|------|------|
| **BJ.1** | token claims 增加 **`sid` = `voice_session_id`**（Server 侧一次语音会话标识，05 §2.1 已有此 ID） |
| **BJ.2** | SFU 侧 **会话键 = `sid`**（不是 `user_id`）：热迁移 CONNECT 阶段同一用户在新旧节点各持一会话（新 token 新 `sid`），互不冲突 |
| **BJ.3** | 控制通道的 `RevokeSession` / `DisconnectUser` 指令 **可按 `sid` 精确定位**（也支持按 `uid+rid` 批量） |

```text
// 修订后 claims（其余同 03 §6）
{ "v":1, "uid":…, "gid":…, "cid":…, "nid":…, "rid":…, "sid":…,
  "caps":[…], "iat":…, "exp":…, "jti":… }
```

## 7. Newt-SFU 进程结构（BK）

```text
newt-sfu/
├── cmd/newt-sfu/            # 入口：配置、生命周期、SIGTERM → 上报请求 Drain
└── internal/
    ├── enroll/             # 一次性 token → 本地私钥 + CSR → 领证书（03 §4）
    ├── control/            # gRPC mTLS 外连：一条双向流承载注册/心跳/指令+ACK
    │                       #   指令幂等（command_id 去重窗口）
    ├── auth/               # Media Token 验签（Ed25519，kid 轮换）+ 吊销表
    ├── signal/             # WSS 信令端点（BF）+ /rtt
    ├── room/               # local room / participant（键=sid）/ caps 执行
    ├── sfu/                # Pion：PC 管理、track fanout、订阅图
    ├── cascade/            # epoch/租约校验、边生命周期、NodeWant 剪枝、
    │                       #   环路防御（非父/子来源即丢，08 C.5）
    ├── migrate/            # 迁入 pre-warm / 迁出 RemoveParticipant
    ├── stats/              # 容量上报：users/rooms/出口bps/CPU/RSS/屏幕轨数
    └── observability/      # Prometheus /metrics + pprof + slog
```

### 7.1 实现原则

| 原则 | 说明 |
|------|------|
| **全内存零持久化** | 重启 = 节点死亡，由 Server 批量热迁移；不做本地状态恢复（05 §10 一致） |
| **caps 是唯一权限语言** | 舞台/Restriction/mute 状态机全在 Server；SFU 只执行 token/指令中的 caps 开关 |
| **防御性自保** | room 人数、节点总 PC 数设本地硬顶（如 1200），防调度 bug 打爆节点；触顶拒绝并告警 |
| **音频策略** | Opus in-band FEC 开启；SFU 不开音频 NACK、不做 jitter buffer、不重排——纯转发，抗丢包在端侧（04 §3.2 一致） |
| **转发路径零分配** | RTP 包池（sync.Pool）自 M1 起使用，不等压测暴露再改 |
| **屏幕共享预留** | track kind=video 转发路径、`publish_screen` caps 校验、RTCP PLI/FIR 转发接口留位；首期不实装（06 §10） |

## 8. 技术栈（BL）

| 组件 | 选型 |
|------|------|
| WebRTC | `pion/webrtc v4` + `pion/interceptor`（链精简）+ `pion/ice` UDPMux |
| 控制通道 | `grpc-go`，TLS 自定义校验回调内比对证书指纹与节点表状态（03 §5.2） |
| Token | `golang-jwt/jwt v5` + EdDSA（Ed25519；与 Newt-Server 现有依赖一致） |
| 观测 | `prometheus/client_golang` + `net/http/pprof` + `log/slog` |
| WSS 证书 | ACME 自动化（如 autocert / 外部 certbot 挂载，实现期定） |

## 9. 里程碑（BM）

| 阶段 | 内容 | 验收锚点 |
|------|------|----------|
| **M0** | 协议定稿：控制通道 proto、token claims（含 `sid`）、WSS 信令消息、级联信令；落 `docs/协议/` | 双端评审通过 |
| **M1** | 单节点 MVP：enroll + mTLS 心跳 + EnsureRoom + token 验证 + 单房 N 人互听 + 踢人/改 caps + metrics | 04 T5：踢人 P99 < 1s |
| **M2** | bot 压测框架（headless Pion 客户端）+ 04 T1–T4，校准 1000 目标与 GC/buffer | T2/T3 通过 |
| **M3** | 级联：租约/epoch/建边/EdgeUp + 节点间 PC（BG）+ NodeWant 剪枝 | 双节点两用户互听、剪枝生效 |
| **M4** | 热迁移节点侧：pre-warm 双会话（BJ）+ 配合 09 状态机与客户端双 PC | 叶死/根死静音窗口 P99 达标 |
| **M5** | 舞台 caps 执行细化 + 屏幕轨结构预留 | 抱上/抱下 caps 生效 < 1s |

### 9.1 proto/IDL 位置

首期放 **Newt-Server 仓 `proto/` 目录**（与 `docs/协议/` 配套），buf 生成双端代码；发布节奏分化后再拆独立 Newt-Protocol 仓。

### 9.2 Newt-Server 配套依赖（需同步排期）

| 依赖 | 说明 |
|------|------|
| Gateway WebSocket | 目前缺失；`VOICE_SERVER_UPDATE` / `VOICE_MIGRATING` 等事件的载体 |
| `POST /voice/join` + VoiceState | 05 主路径 |
| 节点管理 API | enrollment 占位/审批/enable（03 §4）+ 内嵌 CA 签发 |
| 调度器 v0 | 单节点直选即可支撑 M1 联调，逐步演进到 10 全量打分 |
| 客户端 ICE 失败上报 | BI.2 信号源之一，Gateway 上行事件 |

## 10. 结论汇总

| # | 结论 |
|---|------|
| 1 | 客户端信令 = SFU 自带 WSS（token 首帧；SDP/订阅/speaking 同通道）；WSS 用公网可信证书，节点需域名 |
| 2 | 级联 = 节点间 WebRTC PC + mTLS 信令 + cascade token 三重校验；每 speaker 一 track，slot 复用二期 |
| 3 | 媒体 UDP 单端口 mux（默认 3478），废止端口范围默认值；节点监听口仅 443/8843/3478 |
| 4 | 死亡检出：心跳 5s×3=15s 硬上限 + EdgeDown/客户端 ICE 失败提前触发；判死权威仍仅 Server |
| 5 | token 增 `sid`；SFU 会话键 = `sid`，支撑迁移双会话 |
| 6 | SFU 全内存、caps 唯一权限语言、防御性硬顶、Opus FEC、包池零分配 |
| 7 | proto 首期放 Newt-Server `proto/`；里程碑 M0–M5；Server 侧 Gateway/join/节点管理/调度器 v0 需同步排期 |
