# 可撤销管理审计（Reversible Management Audit）

| 字段 | 内容 |
|------|------|
| **日期** | 2026-07-26 |
| **状态** | 已实现（P0） |
| **范围** | Owl-Server audit / auditundo / auditapi；Owl-Desktop 操作日志；Web 控制台操作日志 |

## 1. 目标

- 所有管理类操作必须写入审计流水
- 可逆操作支持**随时一键撤销**（无 TTL；实体不存在则 409）
- 不可逆操作显式标记，UI 禁止假撤销
- Client 与 Web 均有醒目时间线，卡片支持撤销

## 2. 模型扩展（`model.AuditLog`）

| 字段 | 说明 |
|------|------|
| `reversible` | 写入时是否声明可逆 |
| `undo_status` | `none` / `available` / `undone` / `blocked` / `irreversible` |
| `before_state` / `after_state` | jsonb 快照 |
| `undo_of_id` | 本条若是撤销，指向原日志 |
| `undone_by_id` / `undone_at` | 原日志被哪条撤销 |

历史内容不改写；撤销只更新状态字段并追加 `audit.undo` 记录。

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/audit-logs` | 系统管全量 |
| POST | `/api/v1/admin/audit-logs/:id/undo` | 系统管撤销 |
| GET | `/api/v1/guilds/:gid/audit-logs` | 本服（`VIEW_AUDIT_LOG`） |
| POST | `/api/v1/guilds/:gid/audit-logs/:id/undo` | 本服撤销 |
| GET/POST | `/gapi/v1/guilds/:gid/audit-logs[...]` | 用户端镜像 |

列表项 enrich：`reversible`、`undo_status`、`undo_hint`、`action_label`、`undo_of_id`、`undone_by_id`、`undone_at`。

查询参数：`undo_status=available|undone|irreversible`，`include_state=1` 返回 before/after。

### 错误码

| Code | HTTP | 含义 |
|------|------|------|
| `ALREADY_UNDONE` | 409 | 已撤销 |
| `CANNOT_UNDO_UNDO` | 409 | 不能撤销「撤销」 |
| `NOT_REVERSIBLE` | 409 | 不可逆或无 handler |
| `TARGET_GONE` | 409 | 目标不存在 |
| `INCOMPLETE_SNAPSHOT` | 409 | 快照不足 |
| `MISSING_PERMISSION` | 403 | 无查看或反向业务权限 |

## 4. 撤销语义（P0 handler）

| 原操作 | 补偿 |
|--------|------|
| `moderation.ban` | 解封（不自动 rejoin） |
| `moderation.unban` | 按 reason 再 ban |
| `restriction.create` | lift |
| `restriction.lift` | 按 before 重建 |
| `restriction.update` | 写回 before |
| `rbac.role_*` / member role / channel update / overwrite | 见实现 |
| `guild.update` | 恢复 name/description |
| `moderation.nickname_update` | 恢复昵称 |

不可逆：`guild.delete`、`channel_delete`、`moderation.kick`、消息删除、token 吊销、purge 等。

## 5. 权限

- 列表：`VIEW_AUDIT_LOG` / Owner / SystemAdmin
- 撤销：上述 + 反向操作权限位（如 ban→`BAN_MEMBERS`）
- Owner / SystemAdmin 短路与现有 perms 一致

## 6. UI

- **Desktop** 服管导航「操作日志」+ 时间线卡片撤销；管理员视图顶栏「最近操作」
- **Web** 治理 →「操作日志」时间线 + 撤销确认

## 7. 包路径

- `internal/audit` — 写入 + 目录
- `internal/auditundo` — 补偿执行器
- `internal/auditapi` — HTTP
