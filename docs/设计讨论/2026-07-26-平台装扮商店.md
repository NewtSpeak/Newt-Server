## 1. 范围

### 首期品类（种子）

1. `avatar_frame` 头像框（静态/动态）
2. `profile_border` 资料卡边框（compact + full 双图）
3. `profile_effect` 资料卡内特效（视觉 + 可选音频）
4. `nameplate` 铭牌（渐变 / 视频+底色）

### 能力

- 单品 + 捆绑包
- 标签主题筛选
- 库存 / 装备（账号全局）
- 积分账户 + 兑换；`POST .../points/exchange` 预留（501）
- 品类 DB 注册表 + schema_json，可后台扩展新品类

### 非目标

- 真实支付 / 服内货币账本
- 用户 UGC 上架
- per-guild 装备

## 2. API 摘要

### 用户端 `/gapi/v1`

- `GET /cosmetics/categories|tags|shop`
- `GET /cosmetics/items/:id`、`/cosmetics/bundles/:id`
- `GET|PUT|DELETE /users/@me/cosmetics/loadout[/:slot]`
- `GET /users/@me/cosmetics/inventory`
- `POST /users/@me/cosmetics/claim|purchase`
- `GET /users/@me/cosmetics/points`
- `POST /users/@me/cosmetics/points/exchange` → 501
- `GET /users/:id/cosmetics/equipped`

### 管理端 `/api/v1`（system_admin）

- `/admin/cosmetics/categories|tags|items|bundles|grant|points/grant`
- `PUT /admin/cosmetics/items/:id/assets/:slot`

### Gateway

- `COSMETIC_CATALOG_UPDATE` / `COSMETIC_INVENTORY_UPDATE` / `COSMETIC_LOADOUT_UPDATE` / `COSMETIC_POINTS_UPDATE`

## 3. 铭牌渲染

`mode=video`：底层 `base_color` → 上层视频叠加 → 文字可读遮罩。  
`mode=gradient`：CSS 渐变（可 animated）。

## 4. 与现有系统边界

不替换服内 Badge / Role.Style / 贴图库；装扮叠在头像/资料卡/成员行背景层。
