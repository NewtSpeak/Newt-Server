1. 创建 **Newt-SFU**（Go + Pion）仓库骨架（模块划分见 [15 §7](./2026-07-20-15-SFU节点实现选型.md)）  
2. 起草 **`docs/协议/`** 与 Newt-Server `proto/`（控制面 gRPC、Media Token 含 `sid`、WSS 信令、级联信令）＝ **M0**  
3. Spike：进房 → 双节点级联 → 迁移静音窗口 → 屏幕配额拒绝（里程碑 M1–M5 见 15 §9）
